# Отара — офлайн-учёт овец и коз

Приложение ставится на телефон и работает без интернета. Все записи сначала сохраняются на самом телефоне. Когда появляется сеть, они сами уходят в общую базу, и остальные участники их видят.

Настройка занимает около 20 минут и делается один раз. Удобнее делать её с компьютера. Всё бесплатно: для небольшого хозяйства лимитов Firebase хватит с большим запасом.

---

## Шаг 1. Создайте проект Firebase

1. Откройте https://console.firebase.google.com и войдите аккаунтом Google.
2. Нажмите **«Создать проект»** (Create a project) и назовите его, например, `otara`. Google Analytics можно отключить.
3. На главной странице проекта нажмите значок **`</>`** (Web), чтобы добавить веб-приложение. Название — «Отара». Галочку Firebase Hosting ставить не нужно.
4. Firebase покажет блок `const firebaseConfig = { ... }`. **В самом Firebase его редактировать не нужно и нельзя**: это образец, из которого вы только копируете. Выделите блок от `const firebaseConfig = {` до `};` и скопируйте (Ctrl+C). Если окно уже закрыли, блок можно найти снова: шестерёнка → **Настройки проекта** → внизу **Ваши приложения** → **Конфигурация SDK** (Config).
5. Откройте файл **`config.js`** из архива в Блокноте: правой кнопкой мыши → **Открыть с помощью → Блокнот**. Выделите в нём такой же блок от `const firebaseConfig = {` до `};`, вставьте скопированное (Ctrl+V) и сохраните (Ctrl+S). Последнюю строку `window.FIREBASE_CONFIG = firebaseConfig;` не трогайте.

Можно и по-другому: сначала загрузите все файлы на GitHub (шаг 4), потом откройте там `config.js`, нажмите значок карандаша, вставьте блок и нажмите **Commit changes**.

Это не пароль, его можно хранить в открытом виде. Данные защищают правила из шага 2.

## Шаг 2. Включите базу данных

1. В меню слева: **Build → Firestore Database → Создать базу данных**.
2. Расположение: `eur3 (europe-west)` или ближайшее к вам. Режим — **production**.
3. Откройте вкладку **Rules** (Правила), замените всё содержимым файла **`firestore.rules`** и нажмите **Publish**.

## Шаг 3. Заведите пользователей

1. **Build → Authentication → Начать**. На вкладке **Sign-in method** включите **Email/Password**.
2. На вкладке **Users** нажмите **Add user** и создайте учётную запись себе и каждому, кто будет вести учёт. Почта может быть любой, хоть `petr@otara.ru`: письма туда не отправляются.
3. Закройте посторонним регистрацию: **Settings → User actions** → снимите галочку **Enable create (sign-up)** и сохраните. Теперь войти смогут только те, кого вы добавили сами.

## Шаг 4. Выложите приложение в интернет (GitHub Pages)

1. Зарегистрируйтесь на https://github.com.
2. Нажмите **New repository**, назовите его `otara` и сделайте **Public**.
3. На странице репозитория нажмите **Add file → Upload files** и перетащите все файлы из архива, включая папку `icons`. Нажмите **Commit changes**.
4. **Settings → Pages**: в поле Source выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и нажмите **Save**.
5. Через 1–2 минуты появится адрес вида `https://ваш-логин.github.io/otara/`.
6. Вернитесь в Firebase: **Authentication → Settings → Authorized domains → Add domain** и добавьте `ваш-логин.github.io`.

## Шаг 5. Установите на телефон

1. На Android откройте адрес из шага 4 в **Chrome** при включённом интернете.
2. Войдите своей почтой и паролем.
3. В меню Chrome (⋮) выберите **«Установить приложение»** или **«Добавить на главный экран»**.
4. Готово: значок «Отары» появится среди приложений. Дальше можно работать в поле, на пастбище и в кошаре без связи.

## Что есть в приложении

- **Стадо.** Карточка животного: номер бирки, загон, дата рождения, мать, отец, вес, история. У маток есть блок «Последний окот» с номерами, полом и датой рождения ягнят или козлят.
- **Окот.** В событии «Окот» отметьте мать и укажите, сколько родилось. Для каждого детёныша введите номер бирки и пол — карточки заведутся сразу, с матерью, отцом, датой рождения и загоном матери.
- **Загоны.** Овчарня 1 (19 загонов), Овчарня 2 (19), Козлятник (10), Карантин (10). Нажмите на загон, чтобы увидеть животных, перевести отмеченных в другой загон и назначить рацион.
- **Рационы.** Норма кормов на голову или на весь загон в сутки. Каждый день приложение само списывает со склада расход по всем загонам с рационами. В «Склад → Журнал списаний» можно исправить количество за день или отменить списание, если не кормили.
- **Склад.** Две вкладки: «Корма» и «ГСМ». Для каждой позиции — приход, расход и остаток. У кормов видно суточный расход и на сколько дней хватит. При приходе можно указать сумму, и она попадёт в расходы.
- **Молоко.** Надой утром и вечером по каждой овце и козе, итог по видам за день и месяц. «Отгрузка на сыроварню» вычитает литры из остатка: было 60 л овечьего, отгрузили 50 — осталось 10. Также есть выпойка молодняку и списание брака.
- **Ещё.** План (обработки, ожидаемые окоты, заканчивающиеся корма), финансы, сводка за год, резервная копия.
- **Выгрузка в Excel.** «Ещё → Выгрузка в Excel»: выберите период и листы и нажмите «Скачать Excel». Файл .xlsx сохранится в «Загрузки» телефона, интернет для этого не нужен. Листы: стадо, окоты и приплод, ветеринария, загоны и рационы, остатки и движение кормов, остатки и движение ГСМ, молоко по дням, надои по головам, отгрузки молока, финансы. На страницах «Молоко» и «Склад» есть быстрая выгрузка только этого раздела.

Загоны заданы в начале файла `app.js` (список `BARNS`). Если число загонов изменится, поправьте цифры там.

## Как это работает без интернета

- **Первый вход** нужен с интернетом. После него приложение и все данные хранятся на телефоне.
- **Записи без сети** сохраняются сразу. Вверху экрана будет надпись «офлайн · ждёт отправки». Когда появится связь, она сменится на «синхронизировано».
- **Одновременная правка.** Если двое без связи изменили одну и ту же карточку, останется та правка, что синхронизировалась последней. Новые события, животные и платежи никогда не теряются — это отдельные записи.
- **Резервная копия.** В разделе «Сводка» нажмите «Резервная копия»: на телефон сохранится файл со всеми записями. Сохраняйте его раз в месяц.

## Если что-то не так

| Что видно | Что сделать |
|---|---|
| «Приложение ещё не настроено» | В `config.js` остались шаблонные значения, повторите шаг 1. |
| «Неверная почта или пароль» | Проверьте пользователя в Authentication → Users. Пароль можно сбросить там же. |
| Вход не проходит, ошибка домена | Добавьте адрес сайта в Authorized domains (шаг 4.6). |
| «Нет доступа к данным» | Правила из `firestore.rules` не опубликованы (шаг 2.3). |
| После изменения файлов на телефоне старая версия | Закройте и снова откройте приложение при включённом интернете. При изменении файлов увеличьте номер `VERSION` в `sw.js`. |

## Файлы

- `index.html` — оформление и разметка
- `app.js` — логика приложения
- `config.js` — настройки вашего Firebase (меняете только его)
- `sw.js` — сохраняет приложение на телефоне для работы офлайн
- `manifest.webmanifest`, `icons/` — название и значок при установке
- `firestore.rules` — правила доступа к базе
